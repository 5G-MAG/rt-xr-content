The rules
The JSON schemas of the MPEG repository check each extension object; these rules check what a schema cannot express. Each names the clause of the specification it rests on. The MPEG repository governs the extensions it changed after the PDF, the PDF governs the others; a conflict inside the repository is REPO-CONFLICT information, a schema that differs from the PDF where the PDF governs is SCHEMA-TEXT information.
